## [0.1.0] - 2026-10-19

### Added

- First experimental public release.
- Python standard-library server and portable command interface.
- Chrome tab and window capture through `getDisplayMedia()`.
- Direct LAN WebRTC playback in a compatible TV browser.
- Six-digit receiver pairing with rate limiting and authenticated peer roles.
- Status, diagnostics, quality presets, and optional compatibility controls.
